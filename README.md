<div class="section">
<h2>📌 Project Overview</h2>
<p>
The AI-Powered Customer Retention Prediction System is a Machine Learning–based web application 
designed to predict customer churn and help businesses take proactive retention actions.
</p>

<p>
Customer churn is a critical business problem. Acquiring new customers is significantly more expensive 
than retaining existing ones. This system uses predictive analytics to identify customers likely to churn.
</p>
</div>

<div class="section">
<h2>🎯 Problem Statement</h2>
<ul>
<li>No early warning system for churn detection</li>
<li>Lack of understanding of customer behavior</li>
<li>High customer acquisition costs</li>
<li>Difficulty identifying at-risk customers</li>
</ul>
</div>

<div class="section">
<h2>💡 Solution Approach</h2>

<h3>🔄 Workflow</h3>
<ol>
<li><strong>Data Collection:</strong> Kaggle Telco dataset</li>
<li><strong>Data Preprocessing:</strong> Missing values, encoding, scaling</li>
<li><strong>Feature Engineering:</strong> Tenure, usage, billing patterns</li>
<li><strong>Model Building:</strong> ML algorithms</li>
<li><strong>Evaluation:</strong> Accuracy, Precision, Recall, ROC-AUC</li>
<li><strong>Deployment:</strong> Flask web app</li>
</ol>

</div>
